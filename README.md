
# 1. Présentation du sujet 

Un développeur a transformé un point-virgule manquant en jeu vidéo. Le joueur est 
placé dans un bureau dont les murs sont tapissés de code imprimé. Quelque part 
parmi 187 421 lignes de code se cache un point-virgule manquant. Il faut se déplacer 
dans la pièce, inspecter le code ligne par ligne, et le trouver sans barre de recherche, 
sans correcteur, sans outil de debug.

# 2. Analyse du besoin — Fonctionnalités attendues 

Nous avons pour objectif de concevoir et réaliser ce jeu en respectant une architecture orientée objet propre, 
avec une répartition claire du travail entre les 4 membres du groupe. 
Objectif pédagogique : manipuler l'héritage, l'encapsulation, les collections d'objets, la 
génération de données, l'optimisation d'affichage (rendu à la demande) et le travail collaboratif 
avec Git.
